⚡

Real-Time Updates

Spring Boot WebSocket with STOMP protocol pushes coordinate broadcasts instantly to connected passenger maps.

Haversine Formula

Mathematical great-circle distance algorithm accurately calculates proximity and sorts autos by closest distance.
